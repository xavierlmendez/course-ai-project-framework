# Grill round 1 — root decisions (2026-09-08)

| # | Question | Decision |
|---|----------|----------|
| Q1 | Deliverable form | Small repo: framework doc + templates + grill transcript + glossary |
| Q2 | What is assessed | Two project types offered: **Type A** (content mastery, AI as tool; understanding assured by the tribulations of the work, not TA checks) and **Type B** (specification skill; the specification is the graded object) |
| Q3 | Internet requirement | Primary: a professor-controlled **published resource** the harness must retrieve, carrying the twist. Secondary option to document: research-process variant |
| Q4 | No paid subscription | Students may use any free tier; grade comes only from a **reference harness** the TAs run |
| Q5 | What broke before | Temperature not controlled across students; each student effectively got best-of-N with varying settings; students with better model access did better (not accounted for) |
| Q6 | Scale | 2 TAs per course, 2 sections, 30–90 students/section (~1 TA : 65 students), 3–5 weeks, individual or pairs |
| Q7 | Graduate version | Same project, higher bar, no added TA load |
