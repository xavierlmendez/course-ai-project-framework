NIGHT 6 — EXPERIMENT 4: template-based no-think slot  ***THIS IS THE FIX***
================================================================================
Model built: ref-q3-nothink  (ollama create ref-q3-nothink -f /root/Modelfile.nothink)

The stock qwen3:14b TEMPLATE already contains the no-think machinery; it is simply gated
behind $.IsThinkSet, which Ollama's /v1 endpoint never sets. Two one-line edits to the
template make it unconditional:

  PATCH A — always append /no_think to the last user message
    -  {{- if and $.IsThinkSet (eq $i $lastUserIdx) }}
    -     {{- if $.Think -}}{{- " "}}/think{{- else -}}{{- " "}}/no_think{{- end -}}
    -  {{- end }}
    +  {{- if (eq $i $lastUserIdx) }}
    +     {{- " "}}/no_think
    +  {{- end }}

  PATCH B — always prefill an empty think block on the assistant turn
    -  {{ if and $.IsThinkSet (not $.Think) -}}
    +  {{ if true -}}
    (the body it guards is the standard  <think>\n\n</think>\n\n  prefill)

Builder script: /root/mkmodel.py (pulls `ollama show --template qwen3:14b` and applies the
two replacements, asserting both anchors are found). Modelfile: /root/Modelfile.nothink.

ROOT CAUSE: qwen3:14b with thinking ENABLED narrates its tool plan inside <think>, closes
the block, and emits EOS — zero tool calls, zero content. It is not a tool-schema, context,
streaming or timeout problem. Disabling thinking fixes it completely and is also ~13x
cheaper per turn (372 thinking tokens -> 29 useful tokens for the same decision).

WHY THE OBVIOUS FIX DOESN'T WORK: `"think": false` is dropped by Ollama's /v1 endpoint,
and `PARAMETER think false` is rejected by Modelfiles. The template is the only lever that
survives the /v1 path OpenCode uses.
